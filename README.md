# Research Toolkit

A powerful all-in-one research toolkit written in Python.  
Quickly monitor topics, find Reddit trends, check sentiment, track your personal brand, and generate content ideas.

## Features

| Tool                      | Description                                      |
|---------------------------|--------------------------------------------------|
| **Topic Monitor**         | Latest news + web results + Twitter/X mentions  |
| **Reddit Trend Hunter**   | Finds hot and rising posts on Reddit             |
| **Sentiment Checker**     | Simple surface-level sentiment analysis          |
| **Personal Brand Tracker**| See who is publicly talking about you/your brand |
| **Content Idea Generator**| Generates content ideas based on real discussions|
